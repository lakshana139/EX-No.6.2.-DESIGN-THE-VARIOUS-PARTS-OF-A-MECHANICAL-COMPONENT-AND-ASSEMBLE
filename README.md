 EX No.6.2.DESIGN THE VARIOUS PARTS OF A MECHANICAL COMPONENT AND ASSEMBLE
 DATE:23/11/26

AIM: 
To Design the various parts of a mechanical component and assemble it using a bottom-up approach then convert it into the orthographic view

 REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 4 GB of RAM (integrated graphics recommend 6 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

COMMANDS USED:

Align: 
The Align tool allows you to align, distribute or organize selected elements, annotations, tags and text along the axis you specify. Furthermore, the Arrange feature will automatically neatly place your tags around the current view.
The Align plug-in for Autodesk® Revit® can help to save time while producing complex drawings with large sets of annotation.
Just select a few elements and the Align tool will sort them for you.

Derive:
Insert design elements such as Components, Bodies, Sketches, Work geometry, Flat patterns or parameters from another design.
The inserted elements update with changes to the original design

Move: Moves the selected face, body, sketch, or construction geometry a specified distance or angle.
Select the objects to modify then specify the distance or angle. Use set pivot to reposition the manipulator

PROCEDURE:


Software Used: Autodesk Fusion 360

1. Open Autodesk Fusion 360: Open Autodesk Fusion 360 and create a new design. Select the Solid workspace and set the units to millimetres (mm).

2. Create the Seat Sketch: Select Create Sketch and choose the XY plane. Use the Rectangle tool to draw the rectangular shape of the chair seat with the required dimensions.

  <img width="612" height="497" alt="Screenshot 2026-11-16 014036" src="https://github.com/user-attachments/assets/de22369a-212f-4258-9986-9ebee1ac33a8" />


3. Extrude the Seat: Finish the sketch and select the rectangular profile. Use the Extrude (E) command to give the seat the required thickness.

  <img width="450" height="651" alt="Screenshot 2026-11-16 024721" src="https://github.com/user-attachments/assets/b7fd45f2-86f0-44c2-b4be-bad1dca38abc" />


4. Create the Chair Legs: Select the bottom face of the seat and create a new sketch. Use the Rectangle tool to draw the profiles for the four chair legs at the required positions.


<img width="612" height="497" alt="Screenshot 2026-11-16 014036" src="https://github.com/user-attachments/assets/207e0614-8592-432a-8963-4dd7fb7ece24" />


6. Extrude the Chair Legs: Finish the sketch and select the leg profiles. Use the Extrude command to extend the profiles downward and form the chair legs.

<img width="132" height="102" alt="Screenshot 2026-11-16 015822" src="https://github.com/user-attachments/assets/30f58cf8-7928-407f-8010-58165b64028c" />

 <img width="450" height="651" alt="Screenshot 2026-11-16 024721" src="https://github.com/user-attachments/assets/fb18ead5-f2f8-4d52-badf-e5458b87e065" />
 

7. Create the Backrest Supports: Select the rear portion of the chair seat and create a sketch. Draw two vertical rectangular profiles using the Rectangle tool to form the backrest supports.

  
8. Create the Backrest: Use the Extrude command to extend the vertical profiles upwards. Add horizontal rectangular bars between the supports to complete the backrest.

<img width="450" height="651" alt="Screenshot 2026-11-16 024721" src="https://github.com/user-attachments/assets/4749e7f3-8a37-47eb-84b6-238e5d92d57e" />


9. Complete the 3D Model: Check the alignment and connections of the seat, legs and backrest. Use the necessary Modify tools to improve the edges and overall appearance.


10. Save the Design: Save the completed chair model with a suitable file name in Autodesk Fusion 360.
